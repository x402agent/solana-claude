Use this file as the handoff prompt for any coding or ops agent adapting this repository to the current x402.wtf stack.

## Mission

Adapt Solana Clawd / OpenClawd surfaces to use x402.wtf as the canonical public hub for agents, catalog discovery, registry metadata, automation installs, and x402 payment flows.

```text

Automation:       https://x402.wtf/automation
One-shot install: curl -fsSL https://x402.wtf/automation/install.sh | bash

Agents API root:  https://x402.wtf/api/agents
Agents catalog:   https://x402.wtf/api/agents/catalog
Agents registry:  https://x402.wtf/api/agents/registry

Backrooms:        https://backrooms.x402.wtf
```

Do not introduce `www.x402.wtf`. Use `https://x402.wtf` everywhere unless a specific deployed route requires a subdomain.

## Documentation Rules

- Animated README content stays near the top.
- Repo and API mapping stays near the bottom.
- Root README must mention `x402.wtf`, `backrooms.x402.wtf`, and the one-shot curls.
- Agents README must not claim stale counts like 52/53 agents, 41 one-shots, 21 featured, or 5 templates unless the generated catalog actually reports those values.
- `api.txt` must include `/api/agents`, `/api/agents/catalog`, `/api/agents/registry`, and single-agent catalog URLs.

## Safety Rules

- Do not commit `.env`, private keys, wallet exports, seed phrases, `.vercel/project.json`, or API credentials.
- Do not overwrite unrelated user changes.
- Treat generated `agents/public/api/agents/*` as derived from `agents/src/*.json` plus `agents/build-catalog.cjs`.
- Prefer `rg` for search.
- Prefer `apply_patch` for manual edits.
