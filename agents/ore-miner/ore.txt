What the installer does:
  1. Clones the repo to ~/.clawd/ore-miner (or detects local copy)
  2. Checks Node >= 20, Cargo (optional)
  3. Prompts for API key, RPC, keypair path
  4. Writes .env
  5. npm install
  6. Optionally builds the ore-cli Rust binary
  7. Runs --status to verify chain connectivity
  8. Asks to start the agent (or auto-starts with AUTO_START=true)
  9. Dashboard goes live at http://localhost:3333

The agent uses DeepSeek by default — cheapest frontier model with
built-in thinking mode. The OpenAI SDK talks to api.deepseek.com.

Provider priority (first key found wins):
  1. DEEPSEEK_API_KEY   → https://api.deepseek.com
  2. OPENROUTER_API_KEY → https://openrouter.ai/api/v1
  3. ANTHROPIC_API_KEY  → https://api.anthropic.com/v1

DeepSeek models:
  deepseek-v4-flash   fast + cheap (default)
  deepseek-v4-pro     max reasoning (thinking mode)

Set DEEPSEEK_MODEL=deepseek-v4-pro to enable full chain-of-thought.
The agent captures reasoning_content and surfaces it in the dashboard.

Get a DeepSeek key: https://platform.deepseek.com

WHAT IS IT?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The world's first AI-driven autonomous miner for the ORE v3 protocol on
Solana. DeepSeek (or Claude) runs a continuous CLAWD LOOP —
Observe → Orient → Decide → Act — reading on-chain state and choosing
whether to deploy SOL, claim rewards, checkpoint, or hold, every tick.

A live Socket.io dashboard broadcasts agent state in real time to a
browser: 5×5 square grid colored by EV, countdown ring, CLAWD LOOP
phase badges, agent reasoning pane, scrolling activity log.

THE ORE v3 GAME
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• 25-square grid per round.
• Mining window: ~60 seconds (controlled by board.endSlot).
• Claim window: ~24 hours (round.expiresAt).
• Winning square chosen by on-chain RNG: XOR of 4 chunks of slot hash → % 25.
• Winning-square miners split all losing-square deployments proportionally.
• All miners earn ORE token from the motherlode.

Program ID: oreV3EG1i9BEgiAJ8b177Z2S2rMarzak4NMv1kULvWv

Key accounts (all PDAs):
  Board  seeds: ["board"]          disc: 105
  Round  seeds: ["round", u64 LE]  disc: 109
  Miner  seeds: ["miner", pubkey]  disc: 103

Key offsets — Board:
  roundId   [8..16]   u64 LE
  startSlot [16..24]  u64 LE
  endSlot   [24..32]  u64 LE   ← mining window deadline

Key offsets — Round:
  deployed[25] [16..216]   25 × u64 LE  (lamports per square)
  count[25]    [248..448]  25 × u64 LE  (miners per square)
  expiresAt    [448..456]  u64 LE        ← claim window deadline
  motherlode   [456..464]  u64 LE
  totalDeployed [536..544] u64 LE
  totalMiners   [544..552] u64 LE
  slotHash      [216..248] 32 bytes      ← non-zero = settled
  winningSquare = Number((r1^r2^r3^r4) % 25n) where rx = BigUint64 at offsets 0,8,16,24

STRATEGY LOGIC (what the AI decides)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EV = (totalDeployed - squareDeployed) / squareDeployed
Empty squares → EV = ∞ (deploy here first)
Underbet (EV > 1.0) → statistically favorable
Never deploy when miningOpen = false
Never drop below minReserve SOL
Checkpoint before claiming (checkpointNeeded must be false)
Hold when < 15s remain in mining window

Tools available each tick (one per tick):
  ore_observe_board      reads Board PDA
  ore_observe_round      reads Round PDA + EV analysis
  ore_observe_miner      reads Miner PDA for your wallet
  ore_wallet_balance     SOL balance
  ore_analyze_strategy   full board analysis + recommendation
  ore_deploy             deploys amountSol to squares[] (array of 0–24)
  ore_claim              claims pending SOL + ORE rewards
  ore_checkpoint         checkpoints miner (required before claiming)
  hold                   no-op, logs reason
