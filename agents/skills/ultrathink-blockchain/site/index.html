THE EXTRACTION PROTOCOL

📍 CONTEXT DUMP
Prime the model with chain-native context. Stack: Helius + Birdeye + Jito. Set constraints: retry logic, simulation-first, dynamic fees. Prevent web2 patterns from leaking in.
🎯 INTENT DECLARATION
Dimensional goal statements. Not "build a sniper" but "sub-200ms execution via Jito with trailing stops". Include success criteria and non-obvious constraints.
🔍 EXTRACTION INTERVIEW
Force requirements gathering. Ask about existing stack, edge cases, scale expectations, what's already been tried. 3-5 questions at a time. Requirements checkpoint before code.
🧠 ULTRATHINK
Focus deep reasoning on critical areas: TX structure, MEV exposure, state races, security. Don't burn tokens on obvious code. ultrathink about [specific problem].
📋 PLAN MODE
Output before execution: Account schema, instruction flow, error taxonomy, test strategy. Review → steer → execute. The plan is where you catch architecture mistakes.
🔒 CONSTRAINTS
Guardrails that prevent anti-patterns. Retries on all RPC. Simulation before send. Jito for value TXs. Explicit timeouts. Graceful shutdown.
