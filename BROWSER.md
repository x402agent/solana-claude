## ⚡ One-Shot Entry — Always Into The Gateway

Everything runs through the gateway. One command installs the `x402.wtf` CLI, registers a local agent profile, and opens the gateway dashboard.

```bash
# Launch the gateway
curl -fsSL https://x402.wtf/x402.sh | bash

# Skip to TUI cockpit
curl -fsSL https://x402.wtf/x402.sh | X402_TUI=1 bash

# Or via npm
npm install -g x402.wtf && x402.wtf
```

Installed commands (all route through the gateway):

```bash
x402.wtf                 # → https://x402.wtf/gateway
x402.wtf gateway         # → https://x402.wtf/gateway
x402.wtf terminal        # → https://x402.wtf/terminal/free
x402.wtf tee             # → https://x402.wtf/tee
```

## 🔒 TEE Terminal — Confidential AI

> **[x402.wtf/tee](https://x402.wtf/tee)**

RedPill Intel TDX confidential AI terminal. Every response is ECDSA-signed inside the enclave and the attestation is verifiable on Sepolia.

```bash
# Fresh attestation summary
curl https://x402.wtf/api/tee/attestation | jq '.summary'

# Verify a response signature
curl -X POST https://x402.wtf/api/tee/verification \
  -H "Content-Type: application/json" \
  -d '{"requestId":"<id>","responseText":"<text>"}' | jq '.status'

# On-chain Solana attestation proof
curl -X POST https://x402.wtf/api/tee/solana-attest \
  -H "Content-Type: application/json" \
  -d '{"requestId":"<id>"}' | jq '.signature'
```

Proof chain: `ECDSA signature → response hash → TEE attestation → Sepolia DCAP → Solana on-chain anchor`

## ⛏ ORE Mining Dashboard — CLAWD LOOP

> **[x402.wtf/ore](https://x402.wtf/ore)**

AI-driven ORE v3 mining agent. DeepSeek reasoning (thinking mode) drives the CLAWD LOOP — Observe, Orient, Decide, Act — across a 25-square on-chain board. Real-time Socket.io stream from the standalone Node.js daemon.

```bash
# Live board state
curl https://x402.wtf/api/ore/state | jq '.board.squares[0:5]'

# Daemon status (running PID and port)
curl https://x402.wtf/api/ore/daemon | jq '{running, pid, port}'

# Start the daemon
curl -X POST https://x402.wtf/api/ore/daemon \
  -H "Content-Type: application/json" \
  -d '{"action":"start"}' | jq .

# Recent CLAWD LOOP run history
curl https://x402.wtf/api/ore/runs | jq '.[0:3]'
```

## 🔐 Auth & Security Model

- Browser code calls same-origin app routes only — upstream secrets never leave the server.
- Protected admin routes accept `Authorization: Bearer <admin key>` or `x-api-key: <admin key>`.
- Platform API keys are checked through `src/lib/platform/api-auth.ts`.
- Backrooms bearer auth injected by `src/lib/backrooms/api.ts`.
- Trusted DexScreener routes require `x-terminal-secret` — browser code must never call refresh/inject/WS controls.
- Current source: **454 `src/app/api` route files**.
- Live trading routes remain gated by explicit auth, admin/user scope, and confirmation flow.
