# 📚 OpenClawd Examples

🦞 **9 runnable demos** showcasing the OpenClawd stack. Run any with:

```bash
npx tsx examples/<name>.ts
```

---

## 🦞 Agents

### `blockchain-buddies-demo.ts`
Solana-native trading companions — each buddy has a unique wallet, personality, and trading style. Watch them interact with the ocean.

**Category:** Agents  
**What it shows:** Autonomous agent spawning, wallet management, personality systems

---

## 👛 Wallet

### `listen-wallet.ts`
Real-time wallet monitor with Helius webhook integration. Watches for balance changes and parses transaction history.

**Category:** Wallet  
**What it shows:** Real-time balance monitoring, Helius transaction parsing

### `clawd-wallet-demo.ts`
@openclawd/wallet SDK demo — Privy-embedded Solana wallet, AgenticWallet (Grok 4.20), SwapService.

**Category:** Wallet  
**What it shows:** Wallet SDK, Privy integration, swap services

## 📊 Trading

### `ooda-loop.ts`
One complete Observe → Orient → Decide → Act → Learn cycle. No private key required — all public data.

**Category:** Trading  
**What it shows:** OODA loop implementation, market data aggregation, confidence scoring

```bash
npx tsx examples/ooda-loop.ts
```

### `lobster-trader.ts`
pump.fun bonding-curve math, graduation probability calculator, buy/sell simulation against the Anchor IDL.

**Category:** Trading  
**What it shows:** Pump.fun bonding curves, graduation probability, trade simulation

### `x402-payment-demo.ts`
