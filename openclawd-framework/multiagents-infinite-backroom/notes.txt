DEEPSEEK SETUP
--------------
export DEEPSEEK_API_KEY="your_deepseek_api_key_here"
export DEEPSEEK_BASE_URL="https://api.deepseek.com"
export DEEPSEEK_MODEL="deepseek-v4-pro"

uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload

USING VERCEL COMMANDS
---------------------
npm i -g vercel  # to install vercel in cli
vercel .

DEEPSEEK API COMPATIBILITY
--------------------------
- Uses OpenAI-compatible API format
- Base URL: https://api.deepseek.com
- Models: deepseek-v4-flash, deepseek-v4-pro
- Supports thinking mode via extra_body: {"thinking": {"type": "enabled"}}
- reasoning_effort: "high" or "max"

LOBSTERLIBRARY INTEGRATION
--------------------------
- Agent templates follow: sense -> think -> pay -> act -> drift
- Multi-agent orchestration pattern adapted from LobsterLibrary
- 73+ agent library patterns available at https://github.com/x402agent/LobsterLibrary
