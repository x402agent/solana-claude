`clawdrouter/` is the local TypeScript routing package for selecting execution profiles, scoring tool routes, and exposing the router CLI.

## Quickstart

```bash
npm --prefix clawdrouter install
npm --prefix clawdrouter run build
npm --prefix clawdrouter run test
npm --prefix clawdrouter run doctor
```
