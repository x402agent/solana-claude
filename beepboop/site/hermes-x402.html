Architecture

Five layers. One sovereign agent stack.

Layer 1 / Interface
HERMES TUI, clawd CLI, and MCP expose the stack to operators, demos, and external agent tooling.
Layer 2 / Cognitive Core
Observe, orient, decide, act, learn. Multi-agent fan-out turns the OODA loop into an operating system for action.
Layer 3 / Payment Engine
x402, pay.sh, AP2, MPP, SPL USDC settlement, and ClawdRouter keep intelligence purchaseable by machines.
Layer 4 / Dark DeFi
Whale tracking, MEV detection, route splitting, and on-chain context injection sharpen the agent's edge.
Layer 5 / Safety
Three Laws Constitution, deny-first permissions, formal reasoning, and attested agent identity define the floor.
