Launches with bonding curves.

The launch planner emits unsigned JSON for metadata, authorities, p-token program id, curve reserves, graduation, registry, and x402 follow-up.

01

Plan

Generate launch config from the p-token launcher template and review the resulting authority model.

02

Curve

Use a constant-product virtual reserve model to estimate early price, slippage, fees, and graduation target.

03

Graduate

After the real reserve target is reached, stop curve trading, seed AMM liquidity, inspect the mint, and register it.

Curve quote builder.

This browser calculator mirrors the local planner. It is for launch design only and does not send transactions.

Agent surface.

        
MCP tools and resources let local agents read Pinocchio docs, inspect templates, simulate launches, and register verified mints.

      

      

        
Resources
Docs and registry
`solana-clawd://pinocchio`, `solana-clawd://ptoken-launches`, and `solana-clawd://ptokens` are available to MCP agents.

        
Tools
Inspect and quote
`ptoken_inspect`, `ptoken_launch_plan`, and `ptoken_bonding_curve_quote` cover the core launch and explorer loop.

        
Prompts
Launch planning
`ptoken_launch` asks agents to produce an unsigned launch config, checks, test plan, and registry steps.

      

      
Pinocchio and p-token templates are not audited. Review signer checks, PDA seeds, ownership checks, fee math, reserve custody, and close paths before using real value.
