`deep-clawd/` is the TypeScript deep agent loop for OODA-style market observation, dFlow-aware tooling, and paper-first execution research.

## Quickstart

```bash
npm --prefix deep-clawd install
npm --prefix deep-clawd run build
npm run deep:orient
PAPER_ONLY=true npm run deep:paper
```

Live execution requires explicit environment configuration. Keep secrets outside the repo and prefer paper mode for demos.
