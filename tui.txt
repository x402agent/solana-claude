## Repo changes to mirror on the site

- `sdk/package.json` declares the full package set and exposes `harness:packages` plus `one-shot:install`.
- `sdk/scripts/verify-package-harness.mjs` verifies package declarations, installed package metadata, expected bins, and key SDK exports.
- `sdk/install.sh` and `sdk/enter.sh` globally install the full package set.
- root `install.sh` also installs `x402.wtf` and `x402agent-nanoclawd-cli`.
- `tui/src/sdk.ts` reports SDK-installed npm packages from `sdk/node_modules`.

## Verification commands

```bash
npm --prefix sdk run harness:packages
npm --prefix sdk run check
npm --prefix sdk run build
npm --prefix tui run build
```

Use Node 20, 22, or 24. Node 25 emits engine warnings for this repo and for `@openclawdsolana/clawd`.
