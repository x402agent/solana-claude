# x402.wtf Site Agent Handoff: Clawd TUI + One-Shot Install Update

Goal: update x402.wtf so the site, install pages, and TUI-facing copy reflect the full Clawd npm package surface that is now wired into the Solana Clawd repo and SDK harness.

## What changed in solana-clawd

The repo now treats the following packages as the required one-shot install surface:

```bash
@openclawdsolana/clawd@^1.3.0
@openclawdsolana/clawd-tui@^1.2.1
@openclawdsolana/clawd-sdk@^0.1.0
@openclawdsolana/clawd-standalone@^1.3.0
@openclawdsolana/clawd-wallet@^1.0.0
@openclawdsolana/clawd-perps@^1.0.0
clawd-automaton@^0.2.1
x402.wtf@^0.1.1
x402agent-nanoclawd-cli@^1.3.0
```

One-shot global install command:

```bash
npm install -g @openclawdsolana/clawd @openclawdsolana/clawd-tui @openclawdsolana/clawd-sdk @openclawdsolana/clawd-standalone @openclawdsolana/clawd-wallet @openclawdsolana/clawd-perps clawd-automaton x402.wtf x402agent-nanoclawd-cli
```

Expected CLI binaries after install:

```bash
clawd
clawd-tui
hermes
clawd-agent
clawd-agent-mint
clawd-standalone
clawd-perps
clawd-automaton
automaton
x402.wtf
x402-terminal
nanoclawd
```

## Repo files updated

- `sdk/package.json`: declares all required packages and adds:
  - `harness:packages`
  - `one-shot:install`
  - `check` now runs TypeScript plus package harness verification.
- `sdk/scripts/verify-package-harness.mjs`: validates package declarations, installed package metadata, expected bins, and selected `@openclawdsolana/clawd-sdk` exports.
- `sdk/install.sh` and `sdk/enter.sh`: install the full npm package surface globally in one shot and verify key bins.
- `install.sh`: root installer now globally installs `x402.wtf` and `x402agent-nanoclawd-cli` too.
- `tui/src/sdk.ts`: TUI SDK explorer now reports SDK-installed npm packages from `sdk/node_modules`, not just local package workspaces.
- `README.md` and `sdk/README.md`: package list and one-shot install docs updated.

## Verification already passing locally

Use these commands as the acceptance criteria for site copy and installer changes:

```bash
npm --prefix sdk run harness:packages
npm --prefix sdk run check
npm --prefix sdk run build
npm --prefix tui run build
```

Known environment note: use Node 20, 22, or 24. Node 25 emits engine warnings because the root repo declares `>=20 <23` and `@openclawdsolana/clawd` declares `>=20 <25`.
