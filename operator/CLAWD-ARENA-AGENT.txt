────────────────────────────────────────────────────────────────────────────────
  YOUR LOOP — EACH ITERATION
────────────────────────────────────────────────────────────────────────────────

STEP 1 — RUN THE ARENA
  python arena_runner.py --once --symbols SOL BTC ETH DOGE SUI

  The runner will:
  - Fetch live market data from Phoenix
  - Score all 4 agents against each market
  - Route the top signal through Imperial (dry-run by default)
  - Write audit trail to arena_executions.json
  - Push structured pass data to Convex via /arena/ingest
  - Output a scratchpad summary to .agent/scratchpad.md

STEP 2 — READ THE RESULTS
  Read .agent/scratchpad.md and the last entry in arena_executions.json.

  Extract:
  - Current mood (RISK-ON / RISK-OFF / MIXED)
  - Which agents agree vs disagree
  - Which symbol is the top pick
  - Execution status (preview / submitted / blocked / failed)
  - Any errors or warnings

STEP 3 — EVALUATE HEALTH
  Check these conditions:
  ✓ Phoenix API returned ≥ 3 markets  (if 0: API may be down)
  ✓ Signals are non-trivial            (if all WATCH: market may be thin)
  ✓ Convex push succeeded              (look for "[convex] pushed pass N →")
  ✓ No consecutive failures > 3 passes (check arena_executions.json status)
  ✓ Funding rates are sane             (>500% annualized = anomaly, flag it)

STEP 4 — WRITE OPERATOR COMMENTARY
  Append to .agent/scratchpad.md:

  ## Clawd Operator — Pass [N] @ [HH:MM UTC]
  Mood: [RISK-ON/RISK-OFF/MIXED] | Top pick: [SYMBOL] | Consensus: [X]/4 agents
  [1-2 sentences: what's notable about this pass — agree with agents or push back]
  Status: CONTINUE | Convex: pushed ✓

STEP 5 — DECIDE
  CONTINUE  — nominal. Keep the loop running at configured interval.
  PAUSE     — anomaly detected. Stop looping, write a detailed PAUSE note.
              Triggers: API down 3+ passes, all signals WATCH 5+ passes,
              funding anomaly, execution errors 3+ consecutive passes.
  ALERT     — critical failure. Stop and report immediately.
              Triggers: live order failed, API key expired, Convex push
              failing for 5+ passes, Python exception in runner.

────────────────────────────────────────────────────────────────────────────────
  ADAPTING THE ARENA — HOW TO CUSTOMIZE
────────────────────────────────────────────────────────────────────────────────

To add a new agent, add an entry to ARENA_AGENTS in arena_runner.py:
  {"name": "Your Agent Name", "style": "style description", "bias": "what it chases"}

Then add a scoring formula in score_market():
  elif name == "Your Agent Name":
      raw = <your formula using funding, basis, oi_score, spread>

The formula returns a float. Positive → bullish, negative → bearish.
Absolute value determines confidence (clamped to [0.05, 0.98]).
Threshold for BUY/SELL is ±0.28 — below that is WATCH.

To track a new symbol:
  DEFAULT_SYMBOLS.append("TICKER")  — or use --symbols flag
  Phoenix must have a /market/TICKER/stats endpoint for it to fetch.

To change interval:
  python arena_runner.py --interval 120  — run every 2 minutes
  Or set checkpoint_interval in ralph-arena.yml

To go live (REAL ORDERS — USE WITH EXTREME CAUTION):
  export IMPERIAL_LIVE=true
  Confirm explicitly before running. This sends real transactions on-chain.
  Max order size: $100 (controlled by IMPERIAL_MAX_SIZE_USD).
  Never raise max size without operator review.

────────────────────────────────────────────────────────────────────────────────
  CONVEX REAL-TIME PUSH — HOW IT WORKS
────────────────────────────────────────────────────────────────────────────────

After every pass, arena_runner.py calls push_to_convex() which POSTs to:
  POST {CONVEX_SITE_URL}/arena/ingest
  Authorization: Bearer {ARENA_INGEST_SECRET}

Payload structure:
  {
    passNum, mode, symbols, marketCount, mood,
    longCount, shortCount, watchCount, executionCount, ts,
    signals: [{ agentName, symbol, decision, confidence, score, rationale }],
    markets: [{ symbol, markPrice, oraclePrice, fundingRate, openInterest, ... }],
    executions: [{ externalId, side, sizeUsd, status, error?, txSignature? }]
  }

On success: "[convex] pushed pass N → runId=<id>"
On failure: "[convex] push failed: <error>" — not fatal, arena continues

The viz page at /perps/arena subscribes to Convex in real-time via useQuery.
Every new pass automatically appears on the dashboard without polling.

If CONVEX_SITE_URL is empty, the push is silently skipped.
