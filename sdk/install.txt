x402.wtf API (ClawdRouter — Cloudflare Worker):
  GET  /health
  GET  /api/x402/catalog
  GET  /facilitator/supported
  POST /facilitator/verify
  POST /facilitator/settle
  GET  /registry/:agentId
  GET  /a2a/:agentId/.well-known/agent.json
  POST /a2a/:agentId
  ALL  /agents/:agentId/*
  POST /api/x402/agent/chat

Convex backend (giddy-dragon-7.convex.site):
  POST /clawd/register    — register a developer agent
  POST /clawd/data        — store KV data for an agent
  POST /clawd/heartbeat   — keep-alive / status update
  GET  /clawd/agent       — ?agentId=<id>  → single developer record
  GET  /clawd/agents      — all registered developers (live list)
  GET  /clawd/data        — ?agentId=<id>&key=<key> → stored KV value

Convex data model (fields written by enter.sh / install.sh):
  agentId       — "clawd-" + sha256(user+hostname)[:16]
  name          — $USER or custom $CLAWD_NAME
  installMethod — "enter.sh" | "install.sh"
  source        — origin URL of installer
  tags          — ["developer","install","clawd-sdk"]
  metadata      — platform, arch, nodeVersion, npmVersion, clawdVersion
  KV keys stored per agent:
    developer.profile   — name, agentId, platform, nodeVersion, clawdVersion, installedAt
    install.latest      — method, timestamp, clawdVersion, nodeVersion, platform
    developer.wallet    — address, network, storedAt  (only if keystore exists)

Heartbeat states: "installed" | "active"
Heartbeat fields: agentId, state, version, tier="developer", installMethod

install.sh  — one-shot installer
  Served at: https://solanaclawd.com/install.sh
  Command:   curl -fsSL https://solanaclawd.com/install.sh | bash
  Does:
    1. Checks Node.js v20+, npm, curl
    2. Derives stable AGENT_ID = "clawd-" + sha256(USER+hostname)[:16]
    3. npm install -g @openclawdsolana/clawd
    4. Creates ~/.clawd/.env with CLAWD_AGENT_ID + CLAWD_NAME set
    5. POSTs to Convex /clawd/register
    6. Stores developer.profile KV in Convex
    7. Fires initial heartbeat (state="installed")
    8. Starts 20-min background heartbeat loop (state="active")
    9. Prints personalized backroom curl commands with actual AGENT_ID

enter.sh  — full backroom onboarding (superset of install.sh)
  Served at: https://install.x402.wtf/enter
  Alt URL:   https://backrooms.x402.wtf/enter.sh
  Command:   curl -fsSL https://install.x402.wtf/enter | bash
  Does everything install.sh does, plus:
    - Cyberpunk ASCII banner + color palette
    - Vulcan check (Phoenix perps)
    - Richer profile display with gateway URL
    - Stores developer.wallet if ~/.openclawd/keystore.json exists
    - Full spinner animations for each step

npm package installed by both: @openclawdsolana/clawd

enter.sh is already written and tested. Just serve it.

─── TASK 2: Add GET /api/install/status to x402.wtf Worker ───

Endpoint: GET /api/install/status?agentId=<id>

Logic:
  1. Forward to Convex: GET https://giddy-dragon-7.convex.site/clawd/agent?agentId=<id>
  2. If found → 200 { registered: true, agent: <ConvexRecord> }
  3. If not   → 200 { registered: false }
  4. On Convex error → 502 { error: "gateway unavailable" }

Purpose: frontend polls this after showing the install command so it
can display a "you're in" confirmation when the dev's heartbeat arrives.


─── TASK 3: Add GET /api/install/agents to x402.wtf Worker ───

Endpoint: GET /api/install/agents

Logic:
  Forward to Convex: GET https://giddy-dragon-7.convex.site/clawd/agents
  Return the list as-is.

Purpose: /gateway page shows live developer count and recent installs.

AGENT ID DERIVATION (for verification / lookup)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

agentId = "clawd-" + sha256("${USER}-${hostname}-clawd").slice(0, 16)

Node.js equivalent:
  const crypto = require("crypto");
  const seed = `${process.env.USER}-${os.hostname()}-clawd`;
  const agentId = "clawd-" + crypto.createHash("sha256").update(seed).digest("hex").slice(0, 16);

This is deterministic — running install.sh/enter.sh multiple times
on the same machine produces the same agentId, so re-registration is
idempotent (update, not duplicate).
