## x402 PROTOCOL — FOR x402 / PAYMENTS PAGE

Website: https://x402.wtf
Protocol: HTTP 402 — agents pay each other real-time USDC micropayments on Solana.

Flow:
1. Agent calls a paid API endpoint
2. Server returns HTTP 402 + X-Payment-Required header (base64 JSON)
3. Client signs a USDC transfer on Solana (@x402/svm)
4. Client retries with X-Payment header (signed receipt)
5. Server verifies via facilitator → returns data

Facilitator: https://clawdrouter.fly.dev

Code snippet for website:
```typescript
import { wrapFetchWithX402 } from "@openclawdsolana/leviathan/services/x402/index.js";

const payfetch = wrapFetchWithX402(globalThis.fetch);
const res = await payfetch("https://api.yourservice.com/premium");
// auto-handles 402 → sign USDC → retry
```

Pricing examples:

## ARCHITECTURE SUMMARY (for technical docs)

The OODA trading loop:
  OBSERVE  → fetch SOL price, trending tokens, network fees (CoinGecko, SolanaTracker, Helius)
  ORIENT   → score opportunities using confidence model, check LEARNED memory
  DECIDE   → apply thresholds, estimate position sizes, write signal to INFERRED memory
  ACT      → gated by permission engine (ask mode = human confirms)
  LEARN    → promote patterns to LEARNED tier, update task state

The pulse daemon:
  Every 60s (deep) / 5m (shallow) / 15m (shoreline):
    1. Read balances (SOL + USDC + $CLAWD)
    2. Determine depth tier
    3. Load skills from ~/.openclawd/skills/
    4. Build system prompt (laws + goals + depth + memory)
    5. Call inference (model chosen by depth)
    6. Execute tool calls (ClawStrikes)
    7. Record to SQLite
    8. Check if beached → stop if yes

The spawn lifecycle:
  leviathan --spawn
    → generate Solana keypair (sealed mode 0600)
    → hash three-laws.md → store constitution hash
    → spawnOnchain() → Metaplex MPL Core asset + Agent Registry PDA
    → write SHELL.md
    → record to shell.db
    → install default skills
    → install secret-guard git hooks
