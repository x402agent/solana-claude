# 🦞 Lobster Library

> The nano Solana financial trading, deep research, ML prediction market & agentic vision AI agent library.

### Terminal Management

- **Always use background terminals** (`isBackground: true`) for every command so a terminal ID is returned
- **Always kill the terminal** after the command completes, whether it succeeds or fails — never leave terminals open
- Do not reuse foreground shell sessions

### Agent Categories

All agents are Solana-specific: Trading, DeFi, ML/Prediction, Risk, Research, Infrastructure, Agentic.

### Development

```bash
npm run generate   # Regenerate all agents
npm run build      # Build the index
npm run test       # Run tests
```
